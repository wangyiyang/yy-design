# Hero / 产品主视觉 Prompt Template

## Base Template

```
Cinematic wide shot, [CORE_SUBJECT], [DESCRIPTION], 80% negative space, [ACCENT_ELEMENT], dramatic lighting, minimalist, zen aesthetic, ultra-detailed, 8k
```

## Variants

### V1 — Enso in Void（默认）

```
Cinematic wide shot, a massive enso circle drawn in sumi ink floating in dark void, 80% negative space, single vermillion dot at the gap, matte gold leaf texture on the ink stroke, dramatic lighting, minimalist, zen aesthetic, ultra-detailed, 8k
```

### V2 — Mountain Emergence

```
Cinematic landscape, single mountain peak emerging from clouds, sumi ink wash style, vast empty sky, subtle gold leaf on the peak, single vermillion dot as distant sun, dramatic lighting, minimalist, zen aesthetic, ultra-detailed, 8k
```

### V3 — Ink in Water

```
Cinematic macro shot, a single drop of ink falling into still water, creating perfect concentric ripples, sumi ink style, 80% dark negative space, single vermillion reflection in the water, dramatic lighting, minimalist, zen aesthetic, ultra-detailed, 8k
```

### V4 — Brush Stroke Sweep

```
Cinematic wide shot, a single bold brush stroke sweeping across the frame from left to right, sumi ink, starting thick and fading to nothing, 80% negative space, single vermillion dot at the fading end, dramatic side lighting, minimalist, zen aesthetic, ultra-detailed, 8k
```

### V5 — Dissolving Form

```
Cinematic wide shot, a perfect geometric form (square/circle) slowly dissolving into ink particles from one corner, sumi ink style, 80% dark negative space, matte gold leaf particles in the dissolving area, single vermillion dot at the origin point, dramatic lighting, minimalist, zen aesthetic, ultra-detailed, 8k
```

## Style Suffix

Append to all variants:

```
minimalist, zen aesthetic, sumi-e ink wash, 80% negative space, single vermillion accent dot, matte gold leaf texture, luxury brand quality, abstract over literal, suggestion over description, high contrast, cinematic lighting, ultra-detailed, 8k
```

## Negative Prompt

```
ninja, shuriken, katana, ninja headband, cyberpunk, neon, gradient background, multiple red accents, busy composition, literal oriental elements, cherry blossom, koi fish, mount fuji, cartoon, anime, 3d render, glossy, plastic
```

## Naming

```
yy-hero-[variant]-v[N]-[yymmdd].png
```

Examples:
- `yy-hero-enso-v1-260526.png`
- `yy-hero-mountain-v2-260526.png`

# YY Design (Archived)

> [!IMPORTANT]
> This repository has moved to [wangyiyang/design-agent-skills](https://github.com/wangyiyang/design-agent-skills). All future development and releases of `yy-design` happen there.

`yy-design` is now maintained as a sub-skill in the Design Agent Skills collection.

## Install

```bash
npx skills add wangyiyang/design-agent-skills --skill yy-design
```

For a global Codex installation:

```bash
npx skills add wangyiyang/design-agent-skills --skill yy-design -g -a codex -y
```

## Why this repository remains

This repository is retained as a read-only record of its history, releases, and earlier design artifacts. Please open issues, contribute, or follow updates in [design-agent-skills](https://github.com/wangyiyang/design-agent-skills).

# yy-design 品牌重生设计文档

> **目的**：将 yy-design 从 huashu-design 的「同源换皮」状态，改造为具有独立品牌灵魂的「翊行代码」设计系统。
>
> **背景**：yy-design 当前技术骨架与 huashu-design 高度同源，VI 规范 v1.0 已锁定但尚未深度融入工具体验。
>
> **方案**：深层改造（方案 C）——品牌人格 + 视觉美学 + 工作流哲学三层融合。
>
> **影响**：SKILL.md 语气、配色精确值、新增水墨组件/动效、「一笔」shortcut 工作流、品牌专属能力、文件命名体系、README 品牌定位。
>
> **风险**：改动范围大，需分阶段实施；字体注入依赖 CDN 可用性；水墨动效在低端设备上可能性能不足。

---

## 1. 品牌人格层改造

### 1.1 语气转型

| 位置 | 改造前 | 改造后 |
|------|--------|--------|
| SKILL.md 首段 | "你是一位用HTML工作的设计师" | "我是一位用一行HTML写诗的设计师" |
| 品牌锚点 | 无 | 新增「翊行设计哲学」开篇 |
| 核心原则语气 | 中立指令式 | 克制但有温度，带东方留白美学隐喻 |
| 工作流命名 | "标准流程" | "一笔工作流" |
| 交付仪式 | 无 | 动画产出盖「{翊}」印章水印 |

### 1.2 新增「翊行设计哲学」章节

三大信条，约 200 字，置于 SKILL.md 开篇：

- **简单 + 神秘**：要的是忍者的「气」——克制、安静、若有若无
- **一笔落成**：一行代码即一幅画。不追求面面俱到，追求恰到好处。留白不是空缺，是呼吸
- **代码即笔墨**：花括号是我的砚台，HTML 是我的宣纸。每一行都是一次书写，每一次渲染都是一次落墨

### 1.3 人称呼应

全 SKILL.md 第一人称统一：「我」而非「你」。用户是「同路人」而非「manager」。

## 2. 视觉层改造

### 2.1 配色精确对齐 VI v1.0

当前 `yy-color-palette.css` 部分值与 VI 规范有偏差，需修正：

| 颜色 | 当前值 | 目标值（VI 规范） |
|------|--------|------------------|
| 墨黑 | `#1A1A1A` | `#0A0A0A` |
| 宣白 | `#FFFFFF` | `#FAFAFA` |
| 朱红 | `#C41E3A` | `#C0392B` |
| 哑金 | `#D4AF37` | `#B8860B` |

扩展色阶基于正确主值重新生成。

### 2.2 字体栈自动注入

所有 HTML 模板输出自动携带 VI 字体，通过 CSS `@import` 加载：

| 层级 | 中文字体 | 英文字体 | 用途 |
|------|----------|----------|------|
| 中文标题 | 思源宋体 SemiBold | — | H1-H3，书卷气 |
| 中文正文 | 思源黑体 Regular/Medium | — | 正文、UI |
| 英文 | — | Inter SemiBold/Regular | 英文标题、tagline |
| 代码 | — | JetBrains Mono Regular | 代码块、技术术语 |

字体源：Google Fonts CDN（Inter、JetBrains Mono）+ 中文 CDN（如 loli.net）或本地回退。

### 2.3 新增「水墨排版」组件

5 个 React/CSS 组件，供 HTML 产出引用：

| 组件名 | 功能 | 品牌隐喻 |
|--------|------|----------|
| `InkBlock` | 引用块：墨黑底色 + 朱红左竖线 | 传统批注/批校符号 |
| `SealMark` | 文末印章：朱红圆角方块 + 小字 | `{翊}` 印章数字变体 |
| `BreathingSpace` | 留白容器：自动 70%+ 负空间 | 80% 留白原则程序化 |
| `VermillionDot` | 单点高亮：朱红圆点，仅 1 处 | 「永远只用 1 个朱红点」铁律 |
| `SumiDivider` | 分隔线：墨黑渐变淡出 | 墨分五色的数字表达 |

组件存放：`assets/components/`（新建目录）。

### 2.4 新增「水墨动效」预设

5 种 CSS/JS 动效，作为 `animations.jsx` 的扩展：

| 动效名 | 效果 | 适用场景 |
|--------|------|----------|
| `ink-reveal` | 内容像墨水滴入水中般从中心晕开 | Hero 标题出场、logo 浮现 |
| `brush-stroke` | 元素沿笔画路径绘制，带飞白纹理 | 标题文字、分割线、边框 |
| `seal-stamp` | 朱红印章从上方落下，带弹性回弹 | 品牌水印、文末签、确认标记 |
| `paper-fade` | 场景像宣纸翻页般淡入淡出 | 幻灯片转场、视频 scene 切换 |
| `enso-draw` | 禅圆（缺口圆环）一笔画成 | Loading、进度指示、装饰元素 |

### 2.5 品牌资产协议升级

现有「核心资产协议」增加 VI 约束层：

- 采集到品牌色后，自动映射到「墨黑白金」四色框架
- 生成的 `brand-spec.md` 自动附加 VI 合规检查清单
- AI 生成配图时自动注入 VI style suffix（`minimalist, zen aesthetic, sumi-e ink wash, 80% negative space, single vermillion accent dot...`）

## 3. 工作流层改造

### 3.1 「一笔工作流」shortcut 层

在现有 10 步标准流程之上，新增 shortcut overlay：

| 步骤 | 原名 | 新名 | 动作 |
|------|------|------|------|
| 1 | 理解需求 | **落墨** | 一句 prompt 自动解析意图 + 提取品牌资产 |
| 2 | Junior + Full pass | **成形** | 自动生成 assumptions，用户确认后一笔完成 |
| 3 | 验证 + 导出 | **钤印** | 自动验证 + 导出 + 盖 `{翊}` 水印 |

### 3.2 快捷指令

| 指令 | 效果 | 底层执行 |
|------|------|----------|
| `一笔[类型]` | 跳过 clarifying，直接做 | 注入默认假设 → 走完整流程 → 交付 |
| `速写[主题]` | 5 分钟草图 | Junior pass → 直接交付灰框版 → 用户说「细化」再填 |
| `钤印` | 当前作品直接导出 + 加水印 | 验证 → 导出 → 盖 `{翊}` → 交付 |

### 3.3 工作流命名诗意化

| 旧名 | 新名 | 隐喻 |
|------|------|------|
| 标准流程 | 「一笔工作流」 | 一笔落成 |
| Junior pass | 「起稿」 | 书法草稿定位 |
| Full pass | 「着色」 | 草稿确认后正式落墨 |
| 验证 | 「审帖」 | 装裱前检查瑕疵 |
| 导出 | 「钤印」 | 盖章落款，作品完成 |
| 专家评审 | 「品评」 | 文人雅集互相点评 |

### 3.4 非破坏升级原则

- 用户说「一笔…」→ 走 shortcut，3 步出稿
- 用户不说「一笔」→ 仍走完整 10 步流程
- shortcut 执行中若检测到复杂需求 → 自动降级为完整流程
- **哲学：简单的事一笔过，复杂的事慢慢磨**

## 4. 能力差异化层改造

### 4.1 核心策略

huashu 做「广」——原型/动画/幻灯片/视频/评审，样样都有。yy 做「深」——在关键能力点上注入品牌灵魂，让用户感受到「只有翊行代码能做出这个味道」。

### 4.2 差异化能力矩阵

| 能力 | huashu 版本 | yy 差异化版本 | 品牌锚点 |
|------|-------------|---------------|----------|
| 品牌资产生成 | 通用 AI 生图（无品牌约束） | `{翊} 风格一键生成`——自动注入 VI 色/字体/留白/水墨风格 | Code, one stroke at a time. |
| 动画动效 | 通用 motion（fade/slide/scale） | `水墨动效引擎`——墨晕/笔迹/印章/宣纸/禅圆 | 一笔落成 |
| 设计方向顾问 | 20 种设计哲学平等推荐 | `东方极简优先`——默认先推 Kenya Hara/原研哉/翊行墨 | 简单+神秘 |
| 解说视频 | 通用 TTS + 动画 | `水墨叙事`——水墨转场 + 朱红字幕 + 宣纸质感背景 | 留白即呼吸 |
| 设计评审 | 5 维度通用评分 | `留白审计`——新增负空间/朱红点/字体合规 3 项品牌检查 | 克制、安静 |

### 4.3 `{翊} 风格一键生成`

用户说「生成我的公众号封面」时：

1. 自动注入 VI 约束：墨黑 `#0A0A0A` + 朱红 `#C0392B` + 80% 留白 + 思源宋体
2. 自动选择场景模板：公众号封面 → `{翊}` 居中偏上 + 黑体小字
3. 自动生成 prompt：基于 VI 规范中的 style suffix 和场景模板
4. 输出附带「品牌合规检查」——朱红 ≤1 处、留白 ≥70%

### 4.4 「留白审计」评审维度

在现有 5 维度（哲学一致性/视觉层级/细节执行/功能性/创新性）基础上，新增 3 项品牌专属检查：

- **负空间比例**：画面留白是否 ≥70%？不足则建议删减元素
- **朱红点数量**：单画面中朱红 accent 是否超过 2 处？超过则建议合并
- **字体合规**：是否使用了禁用字体（微软雅黑/Arial 等）？

### 4.5 东方极简优先模式

当用户说「推荐风格」时，默认先展示东方哲学派 3 个方向：

1. **Kenya Hara 式空**——信息的「空」与留白的力量
2. **原研哉式白**——「白」不是颜色，是感受性
3. **翊行代码式墨**——墨黑 + 朱红 + 80% 留白

其余 17 个流派作为「更多选择」后置展示。

### 4.6 MiniMax TTS 深度绑定

MiniMax TTS 不仅保留，还与「水墨叙事」深度绑定：

| 维度 | 当前 | 改造后 |
|------|------|--------|
| 默认音色 | MiniMax 通用 | 选一个克制、低沉、有「文人」质感的音色 |
| 字幕样式 | B 站风深墨字+白光晕 | 朱红字幕 + 宣纸背景 + 水墨淡入 |
| 音频层 | 纯人声 | 人声 + 水墨 ambient（极淡研墨声/翻纸声） |
| 开场/结尾 | 无 | 开头「墨滴落纸」SFX + 结尾 `{翊}` 印章声 |

## 5. 交付物与文件结构改造

### 5.1 目录命名诗意化

| 旧目录 | 新目录 | 隐喻 |
|--------|--------|------|
| `_output/` | `钤印/` | 盖章落款 = 作品完成 |
| `_temp/` | `草稿/` | 书法草稿纸 |
| `demos/` | `帖/` | 字帖 = 范本展示 |
| `references/` | `法帖/` | 临摹参考的法书 |
| `showcases/` | `展/` | 展览陈列 |
| `assets/sfx/` | `声/` | 声韵 |

**注**：`scripts/`、`assets/components/` 等纯技术目录保持原名，避免过度诗意化导致困惑。

### 5.2 文件命名规则

统一格式：`yy-{type}-{subject}-{variant}-{yymmdd}.{ext}`

示例：`yy-og-aitool-v2-260531.png`

Type 对照：

| Type | 用途 |
|------|------|
| `avatar` | 头像 |
| `banner` | 横幅 |
| `og` | 分享卡 |
| `cover` | 封面 |
| `wechat-cover` | 公众号封面 |
| `logo` | Logo 变体 |
| `hero` | 产品主视觉 |
| `slide` | 幻灯片 |
| `proto` | 原型 |
| `anim` | 动画 |

### 5.3 README 品牌定位重写

首段从功能介绍转为品牌叙事：

> **改造前**："YY Design is a skill — a structured prompt package that any compatible AI coding agent can install."
>
> **改造后**："YY Design is a brush — one line of prompt, one stroke of design. Install it, speak your intent, and watch your idea form like ink on paper: deliberate, restrained, unmistakably yours."

### 5.4 新增品牌专属触发词

保留所有现有触发词，新增：

| 触发词 | 含义 |
|--------|------|
| `一笔` | shortcut 模式，跳过 clarifying 直接做 |
| `速写` | 5 分钟草图，灰框 placeholder 版 |
| `钤印` | 导出并加水印 |
| `水墨` / `墨韵` | 强制使用水墨动效 + 书法排版 |
| `留白` | 触发留白审计评审 |
| `{翊}` | 生成品牌资产（头像/banner/og） |

### 5.5 品牌资产引用规范

#### Logo

- **文件**：`assets/yixing-logo-master.svg`
- **使用场景**：
  - README.md / README.zh.md 顶部居中展示（首屏品牌识别）
  - GitHub 仓库社交预览（Settings → Social preview）
  - SKILL.md 产出中涉及品牌展示时，以 `<img>` 引用 SVG，不手画
  - 动画产出末尾水印（`seal-stamp` 动效版 `{翊}`）
- **安全间距**：Logo 四周留白 ≥ 字高 50%
- **最小尺寸**：屏幕 ≥32px，印刷 ≥15mm
- **禁止**：拉伸、改色、加阴影、与其他 logo 紧贴

#### 微信公众号二维码

- **文件**：`assets/yixing-wechat-qrcode.jpg`
- **使用场景**：
  - README.md / README.zh.md 底部作者信息区（引导关注）
  - 公众号文末签（与 `{翊}` 印章并列）
  - 品牌 contact 卡片 / 名片背面
- **显示尺寸**：README 中 120×120px，保持清晰度
- **禁止**：裁切边框、加滤镜、与其他二维码并排混淆

#### 品牌资产文件清单（纳入版本控制）

### 5.6 品牌一致性校验清单

交付前自动/手动执行：

- [ ] 配色：是否只用了墨黑/宣白/朱红/哑金？
- [ ] 朱红：单画面中朱红 accent 是否 ≤2 处？
- [ ] 留白：画面负空间是否 ≥70%？
- [ ] 字体：中文标题是否用思源宋体/黑体？禁用字体是否出现？
- [ ] 水印：动画产出是否带 `{翊}` 水印？
- [ ] 语气：SKILL.md 输出是否带「一笔落成」的克制感？
- [ ] 命名：文件是否遵循 `yy-{type}-{subject}-{variant}-{yymmdd}`？

## 6. 实施优先级

### Phase 1（高优先级，1 周内）

1. **配色修正**：修正 `yy-color-palette.css` 色值对齐 VI v1.0
2. **语气改造**：重写 SKILL.md 首段 + 新增「翊行设计哲学」章节

4. **触发词新增**：在 SKILL.md description 中注入新增触发词

### Phase 2（中优先级，2 周内）

5. **字体注入**：在所有 HTML 模板输出中自动注入 VI 字体栈

9. **水墨动效预设**：实现 5 种水墨动效（ink-reveal、brush-stroke、seal-stamp、paper-fade、enso-draw）

12. **{翊} 一键生成**：品牌资产生成的 VI 自动约束
13. **东方极简优先**：设计方向顾问默认展示东方哲学派
14. **MiniMax TTS 水墨叙事**：朱红字幕 + 宣纸背景 + 水墨 ambient

## 7. 验收标准

| 检查项 | 通过标准 |
